# Link Swap Matcher

Paste a swap post (Facebook, Messenger, anywhere) and see which of the weeks on offer line up with your own link: day by day, which of your PM / AM3 shifts get better, BLP/SLP balance, and Mon–Sat / Mon–Fri part-week swaps. Tick the matches and copy them in one message.

- Upload your Link/Diagram roster PDF once; it is read and kept on your phone only.
- Install: open the page, then Share → Add to Home Screen (iPhone) or ⋮ → Install app (Android).
- Works offline after the first visit.

Files: `index.html` (the whole app), `sw.js` (offline), `manifest.json`, icons.
